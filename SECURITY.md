# Security Policy

## Supported versions

Sunfin is pre-release software. Only the [latest release](https://github.com/sunfin-dev/sunfin/releases/latest) gets security fixes.

## Reporting a vulnerability

Please don't report security problems in a public issue.

Report them privately instead, through GitHub's **[Report a vulnerability](https://github.com/sunfin-dev/sunfin/security/advisories/new)** form, or by email to **sunfin-dev@proton.me**. Include what you found, how to reproduce it, and which version and platform you used.

You'll get an answer within a week. Once a fix is released, the report is published as a security advisory, crediting you unless you'd rather stay anonymous.

## Scope

In scope: the Sunfin apps and the code in this repository.

Out of scope, please report these to their own projects:

- the Jellyfin server: [Jellyfin security policy](https://github.com/jellyfin/jellyfin/security/policy)
- the Moonfin server plugin and code that Sunfin hasn't changed: [Moonfin](https://github.com/Moonfin-Client/Moonfin-Core)
